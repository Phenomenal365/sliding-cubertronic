## Welcome to Sliding Cubertronic! 🧊⚙️

**Sliding Cubertronic** is a challenging 2D grid-based puzzle game featuring **60 handcrafted levels**, smooth sliding mechanics, custom UI settings, and brain-teasing obstacles designed to test your logic.

This is my very first indie game project, built from scratch using the **Godot Engine**!

### 🎮 Play the Game
- **Playable Build:** Available for free on [Itch.io](https://phenomenal365.itch.io/sliding-cubertronic)

### 📌 Key Features
- **60 Unique Levels:** Progressively harder puzzles with increasing mechanical complexity.
- **Grid-Based Sliding Mechanics:** Clean, deterministic 4-directional movement.
- **Custom Settings:** Fully adjustable audio volume, FPS limits, and window modes.
- **Pixel Art Style:** Clean, retro-inspired aesthetic.

### 🛠️ Built With & How to Run
- **Engine:** Godot Engine 4.7.2
- **Language:** GDScript
